# ЛР3. Тестування зручності додатків-конкурентів

Порівняльне тестування Sortly (прямий конкурент) і Google Sheets (непрямий) за однаковими сімома завданнями.

- `test-plan.md` — мета, завдання, підготовка, попередні висновки для прототипу (В1–В5).
- `test-data.csv` — однаковий набір із 12 товарів для імпорту в обидва продукти.
- `ЛР3_Дзядзін_ІПЗ-24-2.docx` — звіт: план, протоколи спостережень, SUS, аналіз.

## Пілотний прогін

`pilot/` — матеріали пілотного прогону сценарію з **учасником**: діаграма спорідненості `l3_board.png` і змодельовані ілюстрації екранів (`s1…s6`).
