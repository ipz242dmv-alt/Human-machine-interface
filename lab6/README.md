# ЛР6. Адаптивний дизайн

Три екрани (Головна, Вибір товарів, Оформлення) для двох нових розмірів — компонування змінюється, а не масштабується.

| Розмір | Точка перелому | Сітка | Навігація |
|---|---|---|---|
| Телефон (ЛР5) | 360–767 px | 4 кол., поля 16, проміжок 12 | нижня панель |
| Планшет `tablet/` | 768–1279 px | 8 кол., поля 24, проміжок 16 | бічна рейка |
| Монітор `desktop/` | від 1280 px | 12 кол., поля 28, проміжок 20 | бічне меню |

- `ЛР6_Дзядзін_ІПЗ-24-2.docx` — звіт з обґрунтуванням адаптивних рішень.
